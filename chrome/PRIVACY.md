# Datenschutzerklärung / Privacy Policy

## Dashboard & Zwischenablage - Chrome Extension

**Letzte Aktualisierung:** Januar 2026

### Datenspeicherung

Diese Extension speichert alle Daten **ausschließlich lokal** auf deinem Gerät mittels der Chrome Storage API (`chrome.storage.local`). 

Gespeicherte Daten umfassen:
- Aufgaben (Kanban-Board)
- Zwischenablage-Einträge (Text und Bilder)
- Arbeitszeit-Sessions

### Keine Datenübertragung

- Es werden **keine persönlichen Daten erfasst**
- Es werden **keine Daten an externe Server übertragen**
- Es gibt **kein Tracking oder Analytics**
- Es werden **keine Cookies** verwendet

### Berechtigungen

Die Extension benötigt folgende Berechtigungen:
- `storage`: Zum lokalen Speichern deiner Aufgaben und Einstellungen
- `tabs`: Um zu prüfen, ob das Dashboard bereits geöffnet ist

### Datenlöschung

Alle gespeicherten Daten können jederzeit gelöscht werden durch:
1. Entfernen der Extension aus Chrome
2. Löschen der Browserdaten

Bei Fragen zur Datenschutzerklärung kannst du ein Issue im GitHub Repository erstellen.
